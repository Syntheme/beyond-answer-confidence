A model can be wrong in two ways: hesitantly, or so confidently that nobody checks.

A new kind of AI model, the decision model (also called a System One model), is built for automated decisions. It doesn't write text: it picks from a fixed set of options and returns a probability for each one. Software can use those probabilities directly: act automatically when the model is sure, and send the case to a person when it isn't. We tested the best-known one: Jev, from TypeSafe AI.

A gate like this is only as good as the number it checks. Picture a bank routing thousands of support messages an hour. Nobody reads each one, so the confidence number decides which ones a person sees. If it drops when the model doesn't know the answer, the second model in Figure 1 gets stopped. If it doesn't, the mistake goes straight through. TypeSafe says Jev's confidence does drop. Its launch post promises:

"Calibrated decisions: answers with epistemically honest probabilities on System One tasks." TypeSafe, Introducing System One models and Jev, accessed 29 September 2026

That's really two promises. The first is calibration: when Jev says 80%, it should be right about 80% of the time. The second is harder: when Jev doesn't have what it needs, its confidence should show it. A model can keep the first promise and still break the second, and the second is the one the gate depends on. (By "confidence" we mean the probability Jev gives its chosen answer, not the separate confidence field in its API.)

We tested both claims in about 575,000 Jev calls. Four results stood out:

  • On familiar closed-choice tasks, confidence tracked accuracy well and supported useful filtering.
  • When the prompt contained no basis for an answer, or the question fell beyond the observed knowledge boundary, confidence often remained high.
  • “Do you know?” initially appeared to detect these gaps. Under controls for invented-looking names and explicit dates, however, it performed no better than ordinary answer uncertainty.
  • Questions about observable properties of the case held up better. Jev could identify whether the supplied evidence was sufficient and whether an outcome was already settled.
